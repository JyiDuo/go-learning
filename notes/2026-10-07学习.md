# Go 语言基础语法学习笔记（Day 01）

## 一、 包（Packages）与代码组织

### 1. 程序的组成
*   每个 Go 程序都由包（Package）组成。
*   程序入口：`package main` 和 `func main()`。只有 `main` 包才能编译成可执行文件。

### 2. 导入包（Import）
*   **推荐写法（分组导入）**：使用括号 `()` 将多个包放在一起，代码简洁。
    ```go
    import (
        "fmt"
        "math/rand"
    )
    ```
*   **不推荐写法（单行导入）**：除非只导入一个包，否则代码冗长。
    ```go
    import "fmt"
    import "math"
    ```

### 3. 导入路径 vs 包名（易错点）
*   **导入路径**：`import` 语句引号内的字符串（如 `"math/rand"`）。
*   **包名**：代码中实际调用时使用的名字。**惯例：包名与导入路径的最后一个元素相同**。
*   **代码体现**：调用时写 `rand.Intn(10)`，**不需要**写 `math/rand.Intn(10)`。

### ⚠️ 4. 实战踩坑记录：包名冲突与模块管理
**【坑 1】：同一个文件夹下，不同的文件声明了不同的包名。**
*   **报错**：`found packages gopractice and main...`
*   **铁律**：**在同一个文件夹（目录）下的所有 `.go` 文件，必须属于同一个包。**
*   **解决**：统一改成 `package main`，或者把它们分开存放到不同的文件夹里。

**【坑 2】：找不到主模块（cannot find main module）。**
*   **报错**：`go: cannot find main module, but found .git/config...`
*   **原因**：现代 Go 语言（1.16+）推荐使用 Go Modules 管理代码，你的项目缺少一个“身份证”（`go.mod` 文件）。
*   **解决**：在项目根目录（`go-practice` 文件夹下）打开终端，执行 `go mod init go-practice` 生成 `go.mod` 文件。

## 二、 变量与函数基础

### 1. 导出名称（Exported Names）—— 核心特性
*   **规则**：Go 语言没有 `public/private` 关键字，**首字母大小写决定访问权限**。
*   **首字母大写（Exported）**：公开的，可以被其他包引入并使用（如 `fmt.Println`, `math.Pi`）。
*   **首字母小写（Unexported）**：私有的，只能在本包内部使用（如 `math.pi`）。
*   **记忆口诀**：**“大写走出去，小写家里蹲”**。

### ❓ 2. 疑难解答：为什么小写的函数也能执行？
*   **问题**：既然小写是私有的，为什么 `func add()` 和 `func main()` 都是小写，`main` 却能成功调用 `add`？
*   **解答**：因为**它们在同一个包（Package）里**。
    *   跨包访问（不同文件夹）：必须首字母大写。
    *   包内访问（同一个文件夹、同一个 `package` 声明下）：**无论大小写，都可以自由互相调用。**

### 3. 函数（Functions）基础
*   **语法**：`func 函数名(参数名 参数类型) 返回值类型 { ... }`
*   **核心易错点**：**变量名在前，类型在后**（与 Java/C 相反）。例：`x int`，而不是 `int x`。
*   **简写技巧**：如果多个参数类型相同，可以合并写。例：`(x, y int)`。

### 4. 多返回值（Multiple Results）
*   Go 语言允许函数返回任意数量的结果。
*   **语法**：返回值类型用括号括起来，逗号分隔。`func swap(x, y string) (string, string)`
*   **调用**：使用 `:=` 声明对应数量的变量接收。`a, b := swap("hello", "world")`

### 5. 命名返回值（Named Results）与裸返回
*   **语法**：在返回值列表里写名字和类型 `(x, y int)`。这些变量会在函数开始时自动初始化（零值）。
*   **裸返回（Naked Return）**：只有 `return` 关键字，没有参数。Go 会自动返回当前命名返回值变量的值。
*   **⚠️ 规范**：**仅在极短的函数中使用裸返回**。长函数中使用会严重损害可读性，建议老老实实写 `return x, y`。

## 三、 变量声明（Variables）

### 1. 基本声明语法
*   `var 变量名 类型` （如 `var i int`）
*   可以批量声明同类型变量：`var c, python, java bool`

### 2. 带初始化器的变量声明与类型推断
*   **完整语法**：`var i, j int = 1, 2`
*   **省略类型（类型推断）**：如果提供了初值，可以省略类型。
    `var c, python, java = true, false, "no!"`
    *编译器会根据初值自动推断：`c(bool)`, `python(bool)`, `java(string)`。*

### ❓ 3. 疑难解答：类型推断的细节区别（极其重要）
*   **问题**：为什么 `var c, python, java = true, false, "no!"` 可以省略类型且包含不同类型，而有时又说类型必须一致？
*   **解答**：**根据你使用的声明语法不同，规则有细微差别：**
    1.  **使用 `var` 声明时**：允许在一行内声明**不同类型**的变量。编译器会**从左到右逐一独立推断**每个变量的类型。
        *   `var c, python, java = true, false, "no!"` 是**合法**的。
    2.  **使用 `:=` 短变量声明时（无 `var`）**：要求同一行内声明的所有变量**必须是同一种类型**。
        *   `a, b := 1, "hello"` 会**报错**，因为编译器无法统一定义类型。

### 4. 默认零值（Zero Values）
*   声明变量时如果不显式赋值，Go 会自动给它赋该类型的“零值”。
*   数值类型（int, float）：`0`
*   布尔类型（bool）：`false`
*   字符串（string）：`""` (空字符串)

### ⚠️ 5. 实战踩坑记录：“未使用”报错汇总
Go 语言编译器极其严格，不允许无用的代码：

**【坑 3】：导入了包但没有使用。**
*   **报错**：`"fmt" imported and not used compiler(UnusedImport)`
*   **解决**：删掉包，或者使用包里的函数。

**【坑 4】：在函数内部声明了局部变量，但未使用。**
*   **报错**：`declared and not used: i compiler(UnusedVar)`
*   **解决**：删掉变量，或者把它用起来（打印、赋值给其他变量、参与运算等）。

**❓ 追问：只有局部变量才这样吗？**
*   **正确！**
    *   **严格检查（报错）**：导入的包（`UnusedImport`）+ 函数内部的局部变量（`UnusedVar`）。
    *   **宽松处理（不报错）**：函数外部（包级）声明的全局变量 + 结构体的字段。
