# 📘 Go 语言学习总结（切片、映射与闭包）

> **今日核心内容**：切片（Slice）进阶、映射（Map）全面掌握、函数值（Function Values）与闭包（Closure）。
> **学习方式**：官方教程 + 代码实战 + 深度提问探讨。

## 一、切片（Slice）进阶

### 1.1 `append` 动态扩容
*   **函数签名**：`func append(s []T, vs ...T) []T`
*   **核心机制**：向切片追加元素。如果底层数组容量不足，Go 会自动分配一个更大的新数组，并返回指向新数组的切片。
*   **特性**：`append` 可以作用于 `nil` 切片，会按需自动扩容。

### 1.2 `range` 遍历机制
```go
for i, v := range pow { ... }
```
*   **第一个返回值**：索引（Index）。
*   **第二个返回值**：**元素的副本（Copy）**，而非元素本身。
*   **忽略值的写法**：`for i := range pow`（只取索引） / `for _, v := range pow`（只取值，用 `_` 占位）。

### 1.3 实战练习：生成图片
*   使用 `make([][]uint8, dy)` 创建二维切片。
*   使用嵌套 `for` 循环遍历坐标 `(x, y)`，并用公式（如 `x^y`、`(x+y)/2`）计算像素值。
*   必须使用 `uint8(intValue)` 进行类型转换。

## 二、映射（Map）全面掌握

### 2.1 核心概念
*   **定义**：键值对（Key-Value）集合。
*   **零值**：`nil`。
*   **⚠️ 致命警告**：**`nil` 的 Map 不能写入（添加键值对会 panic），必须先初始化！**

### 2.2 初始化的两种方式
1.  **使用 `make` 函数**：
    ```go
    m := make(map[string]int)
    ```
2.  **使用字面量（声明即初始化）**：
    ```go
    m := map[string]Vertex{
        "Bell Labs": {40.68, -74.39}, // 可省略顶层类型名 Vertex
        "Google":    {37.42, -122.08},
    }
    ```

### 2.3 增删改查（CRUD）
| 操作           | 语法                 | 备注                                                         |
| :------------- | :------------------- | :----------------------------------------------------------- |
| **增/改**      | `m[key] = elem`      | 键存在则更新，不存在则插入                                   |
| **查**         | `elem = m[key]`      | 键不存在返回零值（不报错）                                   |
| **删**         | `delete(m, key)`     | 键不存在则什么都不做                                         |
| **双返回值查** | `elem, ok := m[key]` | **⭐ 核心语法**：`ok` 为 `true` 表示键存在，`false` 表示不存在 |

### 2.4 实战练习：词频统计（WordCount）
*   **工具**：`strings.Fields(s)` 将字符串按空白字符分割成 `[]string` 切片。
*   **核心逻辑**：遍历切片，使用 `counts[word]++` 完成统计（利用 Map 零值特性，不存在时默认从 0 开始加）。

## 三、函数值与闭包

### 3.1 函数值（Function Values）
*   Go 语言中，函数是“一等公民”。
*   函数可以像普通变量一样被赋值、作为参数传递、或作为返回值。
*   **高阶函数示例**：
    ```go
    func compute(fn func(float64, float64) float64) float64 {
        return fn(3, 4)
    }
    ```

### 3.2 闭包（Closure）
*   **定义**：一个函数值，引用了来自其主体外部的变量。
*   **绑定机制**：外部变量被“绑定”到闭包上。只要闭包存活，外部变量就不会被垃圾回收（逃逸到堆上）。
*   **独立性**：每次调用外层函数（如 `adder()`），都会创建一个全新的、互不干扰的闭包环境。

### 3.3 实战练习：斐波那契闭包
*   **核心代码**：
    ```go
    func fibonacci() func() int {
        a, b := 0, 1
        return func() int {
            current := a
            a, b = b, a+b // ⭐ 多重赋值，先算右边再赋左边
            return current
        }
    }
    ```

## 四、⚠️ 避坑指南与注意事项（核心精华）

### 坑 1：切片 `range` 循环中修改值
*   **问题**：`for _, v := range slice` 中的 `v` 是元素的**副本**。
*   **避坑**：修改 `v` 不会影响原切片，必须通过索引 `slice[i] = newValue` 修改。
*   **特例**：若切片存的是指针，可通过 `v.Field = value` 修改底层数据。

### 坑 2：命名冲突
*   **问题**：函数名与导入的包名完全一致（如 `func pic` 与 `"golang.org/x/tour/pic"`）。
*   **避坑**：永远不要让你的函数名、变量名与导入的包名一致。
*   **附带教训**：Go 极其严格，**导入了未使用的包或使用了未声明的变量，都会导致编译失败**。

### 坑 3：Map 未初始化就写入
*   **报错**：`map[string]int (type) is not an expression`。
*   **避坑**：`var m map[string]int` 只是声明，此时是 `nil`。必须使用 `make(map[string]int)` 或 `map[string]int{}` 初始化后才能赋值。

### 坑 4：多重赋值 `a, b = b, a+b` 的底层逻辑
*   **问题**：`a` 的变化和 `b` 的变化是同步的吗？
*   **避坑**：Go 的多重赋值遵循“**先计算右边所有值，再统一赋给左边**”的原则。
*   所以 `a, b = b, a+b` 是安全的，右边的 `a+b` 使用的是**旧的 `a`**。
*   若拆成两行写 `a = b; b = a + b`，会发生数据污染（`a` 已经是新值了）。**

### 坑 5：外网依赖包的下载
*   **报错**：`no required module provides package golang.org/x/tour/pic`。
*   **避坑**：使用 `go get` 下载依赖。国内网络受限时，记得配置代理：
    ```bash
    go env -w GOPROXY=https://goproxy.cn,direct
    ```

### 坑 6：内存泄漏风险（闭包）
*   **问题**：闭包会“死死抓住”外部变量不放。
*   **避坑**：若闭包引用了非常大的对象，且闭包本身长期存活（未置为 `nil`），会导致该大对象无法被 GC 回收，引发内存泄漏。
