# Go 语言基础学习记录 - Day 02

## 📚 今日学习内容概览
今天系统学习了 Go 语言的核心基础语法，包括：变量与常量的声明、基本数据类型、类型转换、控制流（For、If、Switch）、以及延迟执行（Defer）。整体感受是 Go 语言在语法上追求极致的简洁与严谨。

---

## 📝 详细知识点梳理

### 1. 变量声明 (`var` vs `:=`)
*   **标准声明 (`var`)**：`var i int = 1` 或 `var i, j int = 1, 2`。可以显式指定类型，也可以在声明时自动推断。
*   **短变量声明 (`:=`)**：`k := 3`，`c, python, java := true, false, "no!"`。
*   **核心规则**：`:=` 只能在**函数体内部**使用。在函数外部（全局作用域），必须使用 `var` 关键字声明。

### 2. 基本数据类型与零值
*   **基础类型**：`bool`, `string`, `int/uint` (及 8/16/32/64 变体), `byte` (uint8 别名), `rune` (int32 别名), `float32/64`, `complex64/128`。
*   **零值 (Zero Values)**：变量声明但未赋值时，Go 会自动赋予其“零值”：
    *   数值类型：`0`
    *   布尔类型：`false`
    *   字符串类型：`""` (空字符串)
*   **打印技巧**：使用 `fmt.Printf` 配合 `%T` (打印类型) 和 `%v` (打印值) 来观察变量。

### 3. 常量 (`const`) 与 无类型常量
*   使用 `const` 关键字声明，**不能用 `:=` 声明**。可以是字符、字符串、布尔值或数值。
*   **无类型常量 (Untyped Constants)**：如 `const Big = 1 << 100`。这是一个高精度值，不占用具体内存类型。它会根据上下文（如赋值给变量或传入函数）自动转换为所需的类型。

### 4. 类型转换
*   **语法**：`T(v)`，将值 `v` 转换为类型 `T`。
*   **核心规则**：Go 语言**没有隐式类型转换**。不同类型之间赋值或运算，必须显式转换（如 `float64(i)`），否则编译器会报错。

### 5. 控制流：For 循环
*   Go 语言只有 `for` 一种循环结构。
*   **经典格式**：`for i := 0; i < 10; i++ { ... }`。
*   **当作 while 用**：`for sum < 1000 { ... }`。
*   **死循环**：`for { ... }`。
*   **语法注意**：条件表达式**不需要小括号 `()`**，但**必须有大括号 `{}`**。

### 6. 控制流：If 语句
*   **语法注意**：和 `for` 一样，不需要小括号，必须有花括号。
*   **特色语法**：允许在 `if` 中执行初始化语句：`if v, err := getValue(); err != nil { ... }`。
*   **致命陷阱**：`else` 必须紧跟在 `if` 块的右大括号 `}` 后面，**不能换行**，否则会报语法错误。

### 7. 控制流：Switch 语句
*   **核心区别**：Go 的 `switch` 匹配成功后**自动 break**，不需要手动写 `break`。
*   **灵活性**：判断值不必是整数或常量，可以是字符串、表达式等。
*   **评估顺序**：从上到下评估，一旦匹配成功即停止，后面的 `case` 表达式不会被求值。
*   **初始化**：支持 `switch os := runtime.GOOS; os { ... }` 写法。

### 8. Defer (延迟执行)
*   **作用**：将函数调用推迟到外层函数即将返回时执行。
*   **顺序**：多个 `defer` 遵循**后进先出 (LIFO)** 顺序（类似栈）。
*   **核心机制**：`defer` 语句的参数在**声明该行时立即计算**并固定，但函数体直到最后才执行。

## ⚠️ 今日避坑指南（注意事项）

1.  **`:=` 的作用域限制**：千万不要在全局作用域（`func main` 外部）使用 `:=` 声明变量，必须用 `var`。
2.  **`fmt.Println` vs `fmt.Printf`**：不要混淆！`Println` 不会解析格式化占位符（如 `%v`），只会原样输出；`Printf` 才会解析并替换占位符。
3.  **无类型常量的溢出**：虽然常量本身精度极高，但如果把它赋值给一个容量较小的类型（如 `int`），且数值超出该类型范围，编译会报错（溢出）。
4.  **强制类型转换**：不同数值类型（如 `int` 和 `float64`）之间运算，必须显式转换，例如 `float64(a) + b`。
5.  **`else` 的位置**：写 `if-else` 时，`} else {` 必须写在同一行。换行会导致 Go 编译器在 `}` 后自动插入分号，从而引发语法错误。
6.  **Defer 的参数陷阱**：如果 `defer` 调用的函数使用了外部变量作为参数，这个变量的值在 `defer` 声明时就被拷贝了，后续对变量的修改不会影响 `defer` 的执行结果。
