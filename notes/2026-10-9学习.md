## 一、指针（Pointers）

### 核心概念
- **指针**：保存了另一个变量的内存地址。
- **零值**：`nil`。
- **取地址符 `&`**：获取变量的内存地址。
- **解引用符 `*`**：访问指针指向的底层值。

### 示例代码
```go
var p *int      // 声明一个指向 int 的指针
i := 42
p = &i          // p 指向 i
fmt.Println(*p) // 通过指针读取 i 的值（输出 42）
*p = 21         // 通过指针修改 i 的值
```

### ⚠️ 注意事项
1. **Go 没有指针算术**，这与 C 语言不同（不能 `p++`）。
2. **自动解引用**：
   - 当结构体指针访问字段时：`p.X` 会自动转换为 `(*p).X`。
   - 方法调用时：值可以调用指针接收者的方法，指针也可以调用值接收者的方法，Go 会自动转换。
3. **不会自动解引用**的情况：算术运算（`*p + 1` 必须显式解引用）、赋值给非结构体类型变量。

## 二、结构体（Structs）

### 核心概念
- 结构体是一组字段（fields）的集合。
- 使用 `type` 关键字定义。

### 示例代码
```go
type Vertex struct {
    X int
    Y int
}

v := Vertex{1, 2}       // 按位置初始化
v2 := Vertex{X: 1}      // 按字段名初始化（部分，Y 默认为 0）
v3 := Vertex{}          // 空初始化
p := &Vertex{1, 2}      // 创建结构体指针
```

### ⚠️ 注意事项
1. **可见性规则（重要）**：
   - 首字母**大写**（如 `Vertex`、`X`）：**公开的**，可以在其他包中使用。
   - 首字母**小写**（如 `vertex`、`x`）：**私有的**，只能在定义它的包内部使用。
2. **结构体字面量**：
   - 完整写法：`Vertex{X: 1, Y: 2}`
   - 部分字段：`Vertex{X: 1}`，未指定字段自动为零值。
   - 类型写法：`p := &Vertex{1, 2}` 返回 `*Vertex` 类型。
3. **全局变量声明**：函数外声明变量必须用 `var`，不能用 `:=`。

## 三、数组（Arrays）

### 核心概念
- 类型：`[n]T`，表示包含 `n` 个类型为 `T` 的值的数组。
- **长度是类型的一部分**（`[10]int` 和 `[20]int` 是不同类型）。

### 示例代码
```go
var a [2]string
a[0] = "Hello"
a[1] = "World"

primes := [6]int{2, 3, 5, 7, 11, 13}
```

### ⚠️ 注意事项
1. **数组大小固定**，无法调整。
2. **数组是值类型**：赋值或传参时会**整体拷贝**。
3. 日常开发中，**切片比数组更常用**。

## 四、切片（Slices）—— 重点！

### 核心概念
- 类型：`[]T`（方括号里**没有**数字）。
- 切片是**动态大小**的，是对底层数组的一个**视图**。
- **长度（len）**：切片包含的元素数量。
- **容量（cap）**：从切片起始位置到底层数组末尾的元素数量。

### 创建方式
```go
// 1. 切片字面量
s := []int{2, 3, 5, 7, 11, 13}

// 2. 从数组截取
arr := [6]int{1, 2, 3, 4, 5, 6}
s := arr[1:4]  // [2 3 4]

// 3. 使用 make 函数（推荐用于动态创建）
a := make([]int, 5)      // len=5, cap=5
b := make([]int, 0, 5)   // len=0, cap=5
```

### 切片表达式（半开区间）
`a[low : high]`：
- 包含 `low`，**不包含** `high`。
- 省略 `low`：默认为 0。
- 省略 `high`：默认为底层数组长度。

```go
a[0:10]  // 等价于 a[:10]
a[:10]   // 等价于 a[0:10]
a[0:]    // 等价于 a[0:10]
a[:]     // 等价于 a[0:10]
```

### ⚠️ 注意事项（极其重要）
1. **切片不存储数据**，它只是底层数组的引用。修改切片会影响底层数组。
2. **切片的容量公式**：`cap = 底层数组长度 - 切片起始索引`。
3. **可以扩展切片**：只要不超过容量，可以重新切片（如 `s = s[:4]`）。
4. **越界会 panic**：扩展超过容量会报 `slice bounds out of range`。
5. **`make` 三参数形式**：`make([]T, length, capacity)` 预分配容量，提升性能。

## 五、切片的切片（Slices of Slices）

### 核心概念
- 切片可以包含任何类型，包括其他切片。
- 类型表示为 `[][]T`。

### 示例代码（井字棋棋盘）
```go
board := [][]string{
    []string{"_", "_", "_"},
    []string{"_", "_", "_"},
    []string{"_", "_", "_"},
}

board[0][0] = "X"
board[1][1] = "0"
board[2][2] = "X"
```

### ⚠️ 注意事项
1. **访问方式**：`board[行][列]`。
2. **打印技巧**：用 `strings.Join()` 把一维切片拼成字符串，可以简化单层循环的打印。

## 六、格式化打印（fmt 包）

### 三大打印函数对比

| 函数名        | 是否解析占位符 (`%s`, `%d`) |       是否自动加空格       |    是否自动换行     |
| :------------ | :-------------------------: | :------------------------: | :-----------------: |
| `fmt.Print`   |            ❌ 否             |  ✅ 仅当两边都不是字符串时  |        ❌ 否         |
| `fmt.Println` |            ❌ 否             |      ✅ 总是在参数间加      |        ✅ 是         |
| `fmt.Printf`  |            ✅ 是             | ❌ 否（完全按格式字符串来） | ❌ 否（需手动 `\n`） |

### 常用占位符
- `%d`：十进制整数
- `%s`：字符串
- `%t`：布尔值
- `%v`：默认格式（万能）
- `%+v`：打印结构体时带字段名
- `%T`：打印变量的类型
- `%f`：浮点数（`%.2f` 保留两位小数）
- `%p`：指针地址
- `\n`：换行符

### ⚠️ 注意事项
1. **口诀**：要排版用 `Printf`（带 f）；要省事用 `Println`（带 ln）；尽量别用光秃秃的 `Print`。
2. **不要混淆**：`fmt.Print("%s\n", "Hi")` 会原样输出 `%s\nHi`，因为 `Print` 不解析占位符。

## 🎯 今日核心心得

1. **指针是 Go 的重要组成部分**，但 Go 移除了指针算术，更安全。
2. **可见性由首字母大小写决定**，这是 Go 的封装机制。
3. **切片是 Go 中最常用的数据结构**，务必理解 `len` 和 `cap` 的区别与关系。
4. **切片共享底层数组**，理解这一点是掌握 Go 内存模型的关键。
5. **`fmt.Printf` 是最强大的打印函数**，掌握常用占位符非常必要。

---

## 📝 常见错误与避坑指南

1. **全局变量不能用 `:=`**，必须用 `var`。
2. **结构体字面量定义与初始化之间不能换行**（如 `[]struct{...}` 后要紧跟 `{...}`）。
3. **`Print` 不解析占位符**，需要格式化输出时务必用 `Printf`。
4. **切片扩展不能超过容量**，否则 panic。
5. **数组是值类型，切片是引用类型**（本质是包含指针的结构体），传参时行为不同。
