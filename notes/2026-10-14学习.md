

# Go 语言学习笔记（进阶篇）

## 一、错误处理（Error Handling）

### 1. 核心哲学
Go 语言没有传统的 `try-catch` 异常机制。错误（error）被视为一种**普通的返回值**。

### 2. 标准模式
函数如果可能失败，通常返回两个值：`(结果, error)`。
```go
func Sqrt(x float64) (float64, error) {
    if x < 0 {
        return 0, ErrNegativeSqrt(x) // 返回自定义错误
    }
    return math.Sqrt(x), nil // 成功时 error 为 nil
}
```

### 3. 自定义错误类型
要实现 `error` 接口，只需实现 `Error() string` 方法。
```go
type ErrNegativeSqrt float64

func (e ErrNegativeSqrt) Error() string {
    // 注意：必须使用 float64(e) 强转，避免 fmt 调用 Error() 导致无限递归
    return fmt.Sprintf("cannot Sqrt negative number: %v", float64(e))
}
```

### 4. 错误处理机制
- **返回**：函数遇到问题，返回具体的错误值。
- **检查**：调用者检查 `if err != nil`。
- **处理**：打印日志、返回上层或忽略。

## 二、I/O 与 Reader 接口

### 1. io.Reader 接口
代表数据流的读取端，只有一种方法：
```go
func (T) Read(b []byte) (n int, err error)
```
- `b []byte`：数据读入的缓冲区（水桶）。
- `n int`：实际读取的字节数。
- `err error`：读取过程中的错误，`io.EOF` 表示流结束。

### 2. 数据流机制
- Reader 内部维护一个**游标（指针）**，每次读取后停在上次结束的位置。
- **缓冲区更新**：数据是**覆盖式**写入 `b` 的。
- **`b[:n]` 的意义**：只截取本次实际读取的有效数据，过滤掉缓冲区的脏数据。

### 3. 自定义 Reader
实现 `Read` 方法即可拥有 Reader 能力。
```go
type MyReader struct{}
func (r MyReader) Read(b []byte) (int, error) {
    for i := range b {
        b[i] = 'A' // 无限填充 'A'
    }
    return len(b), nil
}
```

### 4. 装饰器模式（Wrapper）
将 Reader 包装在另一个结构体中，在读取时修改数据流（如 ROT13 加密）。
```go
type rot13Reader struct {
    r io.Reader
}
func (r rot13Reader) Read(b []byte) (int, error) {
    n, err := r.r.Read(b) // 先读内部数据
    // 对 b[:n] 进行 ROT13 转换
    return n, err
}
```

## 三、image.Image 接口与图像生成

### 1. 接口定义
```go
type Image interface {
    ColorModel() color.Model
    Bounds() Rectangle
    At(x, y int) color.Color
}
```

### 2. 实现自定义图像
```go
type Image struct{ W, H int }

func (img Image) ColorModel() color.Model { return color.RGBAModel }
func (img Image) Bounds() image.Rectangle { return image.Rect(0, 0, img.W, img.H) }
func (img Image) At(x, y int) color.Color {
    v := uint8(x ^ y)
    return color.RGBA{v, v, 255, 255}
}
```

## 四、泛型（Generics）

### 1. 泛型函数
```go
func Index[T comparable](s []T, x T) int {
    for i, v := range s {
        if v == x { return i }
    }
    return -1
}
```
- `[T comparable]`：类型参数 T，必须是可比较类型。
- `comparable` 约束保证 `==` 和 `!=` 可用。

### 2. 泛型结构体
```go
type List[T any] struct {
    next *List[T]
    data T
}
```
- 适用于实现通用数据结构（如链表）。

### 3. 泛型方法
```go
func (l *List[T]) Push(v T) {
    current := l
    for current.next != nil {
        current = current.next
    }
    current.next = &List[T]{data: v} // 创建新节点并挂载
}
```

## 五、切片 vs 数组

| 特性          | 数组 (Array)       | 切片 (Slice)         |
| :------------ | :----------------- | :------------------- |
| **定义**      | `[5]int`           | `[]int`              |
| **长度**      | 固定，类型的一部分 | 动态，可扩容         |
| **赋值/传参** | 值传递（拷贝）     | 引用传递（共享底层） |
| **底层结构**  | 连续内存块         | 指针 + 长度 + 容量   |
| **使用场景**  | 极少               | 最常用               |

## 六、关键陷阱与注意事项

1. **无限递归**：在 `Error()` 方法中使用 `fmt.Sprintf` 时，确保类型强转，避免调用自身。
2. **切片覆盖**：`Read` 方法是覆盖式写入，务必使用 `b[:n]` 获取有效数据。
3. **链表循环**：遍历链表找尾节点时，条件是 `current.next != nil`，否则会变为 `nil` 导致崩溃。
4. **指针与地址**：`&List[T]{data: v}` 创建并返回一个指向新节点的指针。
