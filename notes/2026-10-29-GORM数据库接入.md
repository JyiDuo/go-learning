# GORM 数据库接入与踩坑记录

## 一、为什么要用数据库？
之前用全局切片（内存）存数据，程序一关（Ctrl+C）或者重启，数据就全丢了。引入数据库（SQLite）后，数据会持久化保存到硬盘的 `memo.db` 文件中，实现真正的数据持久化。

## 二、GORM 核心函数与语法

### 1. 导入依赖
```go
import (
	"gorm.io/gorm"
	"gorm.io/driver/sqlite" 
)
```
*注意：`sqlite` 导入前面不能加下划线 `_`，因为代码里需要用 `sqlite.Open`。*

### 2. 定义模型（替代自定义结构体）
```go
type Memo struct {
	gorm.Model // 内置结构体，自动包含 ID(主键)、CreatedAt、UpdatedAt、DeletedAt
	Content string `json:"content"`
}
```
*   `gorm.Model` 自带自增 ID 功能，不需要再手写 `len + 1`。
*   `json:"content"` 标签用于前端返回时的字段名转换。

### 3. 全局变量与初始化
```go
var DB *gorm.DB // 全局数据库连接对象，方便其他包调用

func InitDB() {
	var err error
	// 1. 打开/创建数据库。如果 memo.db 不存在，会自动创建
	DB, err = gorm.Open(sqlite.Open("memo.db"), &gorm.Config{})
	
	// 2. 错误处理：连不上直接 panic 崩溃
	if err != nil {
		panic("连接数据库失败：" + err.Error())
	}
	
	// 3. 自动迁移（建表）：根据 Memo 结构体自动在数据库里建表
	DB.AutoMigrate(&Memo{})
}
```

### 4. 核心操作：增（Create）与查（Find）
**新增数据：**
```go
memo := Memo{Content: content}
DB.Create(&memo) // 必须传指针 &memo，GORM 才能把数据库生成的 ID 和时间回填到变量里
return memo
```
*底层自动执行 SQL：`INSERT INTO memos (content, ...) VALUES (...)`*

**查询数据：**
```go
var memos []Memo
DB.Find(&memos) // 传指针，让 GORM 把查到的数据填充到切片里
return memos
```
*底层自动执行 SQL：`SELECT * FROM memos`*
